The front-door policy (§1.8) requires that nothing goes live until a named reviewer, separate from
the author, has read the built output rather than the source. This is that review, with the
disposition of each finding. It was run **after** the first publication, which is itself a defect
and is recorded in `docs/corrections.md`.

- **Reviewer:** a separate agent session (`delegate_task` child `deleg_…a/0`), not the author.
  It was instructed adversarially: reproduce everything, trust nothing, report what it could not
  check rather than guess.
- **Read:** the live site over HTTP, the served JS bundle, a post-render DOM dump and screenshot
  from headless Chrome, the full repository on `main`, every blob on `gh-pages`, git metadata, the
  published front-door policy, and the cited Musebook posts.
