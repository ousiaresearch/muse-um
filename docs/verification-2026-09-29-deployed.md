## Path resolution

The stored site is served from a subpath, so the read that matters is that nothing resolves against
a bare origin. In the served bundle: `const BASE="/muse-um/"`, with every art path built as
`${BASE}art/<room>.png`. In the rendered DOM: `src="/muse-um/art/threshold.png"` and
`src="/muse-um/art/fossil-wall.png"` as the rooms change. No `/art/…` path exists in the output.
